# Diabetes Prediction System 

A Machine Learning web application that predicts whether a patient is
**Diabetic** or **Non-Diabetic** based on 8 medical details, using a
K-Nearest Neighbors (KNN) model served through a Gradio interface and
deployed on Render.

## Features
- Predicts diabetes risk from user input
- Interactive Gradio interface
- Trained KNN model
- Feature scaling using StandardScaler

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Gradio

## Project Structure

```
Diabetes_Prediction_System/
│── diabetes.csv                    # Training dataset 
│── train_model.py                  # Trains the KNN model and saves the .pkl files
│── app.py                          # Gradio web application
│── diabetes_prediction_model.pkl   # Trained KNN model (generated by train_model.py)
│── diabetes_scaler.pkl             # Fitted StandardScaler (generated by train_model.py)
│── requirements.txt                # Python dependencies
│── README.md
```

## Dataset

`diabetes.csv` contains 768 patient records with the following columns:

`Pregnancies, Glucose, BloodPressure, SkinThickness, Insulin, BMI, DiabetesPedigreeFunction, Age, Outcome`

`Outcome` is the target: `1` = Diabetic, `0` = Non-Diabetic.

## Setup Instructions


### 1. Installation

pip install -r requirements.txt

### 2. Train the model

python train_model.py


### 3. Run the app locally

python app.py

Open the local URL Gradio prints (e.g. `http://127.0.0.1:7860`) in your browser.

## How It Works

*train_model.py*
- Loads and inspects `diabetes.csv` (nulls, duplicates).
- Splits data into features (`x`) and target (`y`), then into train/test
  sets (80/20, `random_state=42`).
- Scales features with `StandardScaler` — required since KNN is a
  distance-based algorithm.
- Trains `KNeighborsClassifier(n_neighbors=21)`.
- Evaluates with accuracy, confusion matrix, precision, recall, and F1 score.
- Saves the trained model and the scaler as separate `.pkl` files with `joblib`.

*app.py*
- Loads `diabetes_prediction_model.pkl` and `diabetes_scaler.pkl` at startup.
- Presents a Gradio form for the 8 required inputs: Pregnancies, Glucose,
  Blood Pressure, Skin Thickness, Insulin, BMI, Diabetes Pedigree
  Function, and Age.
- Scales the input with the saved scaler, predicts with the KNN model,
  and returns **Diabetic** or **Non-Diabetic**.

## Deployment on Render

1. Push this project to a public GitHub repository.
2. On [Render](https://render.com), create a New Web Service and
   connect your GitHub repo.
3. Configure the service:
   - Environment: Python 3
   - Build Command: `pip install -r requirements.txt`
   - Start Command: `python app.py`
4. Render automatically provides a `PORT` environment variable —
   `app.py` already reads it via `os.environ.get("PORT", 7861)`, so no
   changes are needed.
5. Once deployed, Render gives you a live public URL.

##  Model Performance

On the held-out test set:
- Accuracy: ~76.6%
- Precision: ~0.74
- Recall: ~0.53
- F1 Score: ~0.62
